Privacy Policy

This script accesses only your own YouTube channel data via the YouTube Data API (scope https://www.googleapis.com/auth/youtube.force-ssl). No other Google services are used, and no data is stored or transmitted to third parties.

The generated OAuth token.json file is kept locally in the project directory and is never shared.

If you revoke access in your Google Account or delete token.json, the agent will request a new token on the next run.
